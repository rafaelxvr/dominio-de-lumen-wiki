## Vista Aérea de Sino

*Visão obtida do alto, ao descer pelo Fragmento do Colosso.*

```text
            ┌──────────────────┐
            │     FRAGMENTO     │  <- VOCÊS ESTÃO AQUI
            │  (dedos do        │     (encosta norte, ~50m acima da vila)
            │   Colosso)        │
            └────────┬─────────┘
                     │  (encosta íngreme)
   ─ ─ ─ ─ ─ ─ ─ ─ ─ ┼ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─    NÉVOA DO BOSQUE ÂMBAR
                     │                          (sobe pelas encostas)
            ┌────────┴────────┐
   ┌────────┤   PRAÇA DO SINO  ├────────┐
   │ ESTALAGEM │  [torre/sino] │ │  CASAS    │
   │ "ÚLTIMO   │               │ │ ABANDONADAS│
   │  DEGRAU"  └───────┬───────┘ └───────────┘
   │  (luz)            │
   └───────┐  ┌────────┴───────────────┐
           │  │   ┌──────────────┐      │
           │  │   │  ARMAZÉM     │▓▓▓▓▓▓│
           │  │   │  VELHO       │ OMBRO ▓│  (pedra branca,
           │  │   │  [tapado]    │  DO   ▓│   veios dourados)
           │  │   └──────────────┘ COLOSSO▓│
           │  └────────┬───────────────────┘
           │           │
           │   ══ ESTRADA PARA ENCRUZILHADA ══
```

**Detalhes observáveis:**

| Observação | Detalhe |
|---|---|
| A Vila | 30-40 edificações de pedra escura. Metade com telhados cedidos. Fumaça de ~6 chaminés. Poucas figuras se movendo |
| A Praça | Centro da vila. Torre com sino de bronze verde-escuro, rachado. Imóvel |
| A Estalagem | Único prédio com luz consistente. Placa ilegível à distância. Próxima à encosta norte |
| O Armazém | Periferia leste. Janelas tapadas com tábuas. Dois homens patrulhando. Construído contra uma massa de pedra branca |
| A Pedra Branca | Ombro do Colosso — pedra divina parcialmente enterrada, veios dourados sob musgo |
| Entradas da Vila | Norte (encosta — vocês), oeste (estrada), leste (trilha do rio) |
| A Névoa | Sobe do Bosque Âmbar, envolvendo a base da vila. Densa ao sul e oeste. Rarefeita ao norte |
